# College Campus Voting System

A desktop-based voting application developed using Java, JavaFX, and MySQL as a practice project.

## About the Project

The College Campus Voting System provides a graphical interface for a college voting process. It connects a JavaFX application to a MySQL database to manage student information, display candidates, record votes, and present voting results.

This project helped me gain practical experience in Java application development, database connectivity, and building a graphical user interface.

## Features

- Student login using Student ID
- Candidate display
- Voting functionality
- Vote counting and results display
- Admin functionality for managing student records
- JavaFX-based graphical user interface
- MySQL database integration

## Technologies Used

- **Java** – Application logic
- **JavaFX** – User interface
- **MySQL** – Database management
- **JDBC** – Database connectivity
- **Eclipse IDE** – Development environment

## Database Setup

1. Install MySQL Server.
2. Create the `college_voting` database.
3. Run the SQL commands in `schema.sql` to create the required tables.
4. Configure the `DB_USER` and `DB_PASSWORD` environment variables with your MySQL credentials.

## How to Run

1. Install Java, JavaFX, and MySQL.
2. Clone or download this repository.
3. Open the project in Eclipse.
4. Ensure the database connection settings are correct.
5. Run the application.
